# 数据集与模型权重清单

本文件列出本包使用的全部数据集文件与模型权重文件的各类细节：来源、绝对路径、大小等。

## 1. 数据集

### 1.1 下载来源与公开来源

| 数据                                | 来源                                                                                    |
| ----------------------------------- | --------------------------------------------------------------------------------------- |
| OSMOSIS 数据集                      | https://drive.google.com/drive/folders/1x4hW7ufWyGJFHhqjgQCfF9HAsPwitjuM?usp=drive_link |
| baseline 论文（HTS-Seg 数据集来源） | https://www.sciencedirect.com/science/article/pii/S0169260725005577                     |
| HTS-Seg 原始数据集                  | https://zenodo.org/records/14161434                                                     |
| RxRx1 原始数据集                    | https://rxrx.ai/datasets                                                                |
| OoC 明场原始数据集                  | https://zenodo.org/records/10203721                                                     |

从下载入口获得数据后，需修改 `config.py` 中的绝对路径：`HTS_ROOT`、`RXRX1_ROOT`、
`RXRX1_METADATA`、`OOC_ROOT`、`RXRX1_CACHE_DIR`。

### 1.2 HTS-Seg（Stage 3 任务）

| 项                         | 值                                                                                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 根目录变量                 | `HTS_ROOT`                                                                                                                       |
| 使用子集                   | `cleaned_tiled_images`，2180 张（control 1091 + treatment 1089）                                                                 |
| 图像                       | `{HTS_ROOT}/cleaned_tiled_images/images/{control,treatment}/*.bmp`                                                               |
| 真值掩码                   | `{HTS_ROOT}/cleaned_tiled_images/labels/{control,treatment}/*.tif`                                                               |
| 另一子集（未用于上报指标） | `{HTS_ROOT}/tiled_images/`，2971 张（control 1456 + treatment 1515）                                                             |
| 附带文件                   | `HTS_Seg-main.zip`（baseline 官方代码）、`ReadMe.pdf`、`Help.pdf`、`ImageFeatureDataset.csv`、`spheroid_time_series.csv` |

划分复刻 baseline notebook：`HTS_SUBSET='cleaned_tiled_images'`、`TEST_RATIO=0.2`、
`VAL_RATIO=0.1`、`SPLIT_SEED=42`，得到 train 1569 / val 175 / test 436。

### 1.3 RxRx1（Stage 1 自监督预训练）

| 项             | 值                                             |
| -------------- | ---------------------------------------------- |
| 图像根目录变量 | `RXRX1_ROOT`                                 |
| 元数据变量     | `RXRX1_METADATA`                             |
| 规模           | 51 个 plate（`HEPG2-01` …），六通道荧光 PNG |

**预解码缓存**（Stage 1 训练前置条件）：

| 项           | 值                                        |
| ------------ | ----------------------------------------- |
| 输出位置变量 | `RXRX1_CACHE_DIR`                       |
| 文件         | `rxrx1_ch0-1-4_s256.u8`与同名 `.json` |
| 大小         | 15 972 168 192 字节（约 16 GB）           |
| 生成命令     | `python prepare_rxrx1_cache.py`         |

`.json` 元数据字段：

```json
{"channels": [0, 1, 4], "size": 256, "n": 81224,
 "root": "<RXRX1_ROOT>", "bin": "<RXRX1_CACHE_DIR>/rxrx1_ch0-1-4_s256.u8",
 "bytes": 15969288192}
```

`channels` / `size` / `n` 分别由 `config.py` 的 `RXRX1_CHANNELS`、`RXRX1_CACHE_SIZE`、
`RXRX1_TRAIN_SPLIT_ONLY` 决定，取值同步编入 Stage 1 目录名（`-c014-…-cache256-…-tr1`）。

### 1.4 OoC 明场（Stage 2 域适应目标域）

| 项                 | 值                                                |
| ------------------ | ------------------------------------------------- |
| 根目录变量         | `OOC_ROOT`                                      |
| 布局               | `{train,val,test}/{good,bad}/*`                 |
| 规模（实测文件数） | train 2130 / val 286 / test 656                   |
| 附带文件           | `OOC_datasheet.xlsx`、`OOC_image_dataset.zip` |

## 2. 模型权重

6 个权重位于 `weights/`。

| 文件                  | 大小 (bytes)  | 说明                                       | 用法                                                                                                                  |
| --------------------- | ------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `s3_base.pt`        | 1 080 795 470 | Stage 3 分割模型，基础臂，deconv 头        | 单模型口径默认权重：`test_script.py --mode single`、`evaluate.py --ckpt weights/s3_base.pt`                       |
| `s3_best_seed42.pt` | 1 068 156 814 | Stage 3 分割模型，训练种子 42，bilinear 头 | 集成口径成员：`test_script.py --mode ensemble` 默认加载 42/43/44 三个权重，等价于 `evaluate.py` 传三个 `--ckpt` |
| `s3_best_seed43.pt` | 1 068 156 750 | 同上，种子 43                              | 同上                                                                                                                  |
| `s3_best_seed44.pt` | 1 068 156 750 | 同上，种子 44                              | 同上                                                                                                                  |
| `stage1_encoder.pt` | 345 784 518   | Stage 1 MAE 预训练编码器，150 个键         | 作为 Stage 2 的输入编码器，由`train_domain.py` 加载                                                                 |
| `stage2_best.pt`    | 1 361 084 704 | Stage 2 域适应完整模型，266 个键           | 作为 Stage3 的输入编码器，由`train_seg.py`加载                                                                      |
